A 4 KB Python chess engine: alpha-beta with iterative deepening, a node budget instead of a
clock, piece-square evaluation, quiescence search over captures, killer-move ordering and a
small transposition table. It plays every game through the competition's env and is fully
deterministic, so a trial replays move for move.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 -P -s main.py
```
